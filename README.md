# Galeria Vetor Digital

Plataforma de venda de fotografias esportivas da Vetor Digital ([@vetordigital.lp](https://www.instagram.com/vetordigital.lp/)).

- `galeria-vetor-digital/`: site público, página do pedido e painel administrativo (`/admin`)
- `netlify/functions/`: checkout InfinitePay, webhook, entrega dos originais
- `supabase/schema.sql`: banco, segurança (RLS), armazenamento e busca facial
- `SETUP.md`: passo a passo para colocar no ar

Os arquivos `index.html` e `*-ARUF-*.jpg` da raiz são a galeria antiga (GitHub Pages). Eles continuam funcionando até a migração.
